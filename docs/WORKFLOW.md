# طريقة العمل على نبض

المستودع: https://github.com/waseem-42/Nabd — مفتوح المصدر (AGPL-3.0).

**باختصار:** أشتغل لحالي على `main` مباشرة. ما فيه فروع ولا Pull Requests. GitHub نسخة
محفوظة من الكود، ومنه ينسحب الكود لأي جهاز ثاني.

---

## 1) أول مرة على جهاز جديد

```bash
gh auth login
gh repo clone waseem-42/Nabd
cd Nabd
npm install
npm run dev
```

إعداد هويتك في Git (مرة وحدة لكل جهاز):

```bash
git config --global user.name  "اسمك"
git config --global user.email "بريدك في GitHub"
```

---

## 2) الحفظ التلقائي

المشروع فيه hooks لـ Claude Code (`.claude/settings.json`) ولـ Codex (`.codex/hooks.json`):

| متى | وش يصير |
|---|---|
| **تفتح الجلسة** | يسحب آخر `main`، لو كنت شغّال من جهاز ثاني |
| **كل ما يخلص من رد** | يحفظ تعديلاتك ويرفعها على `main` |

ما تحتاج تسوي `commit` ولا `push` بنفسك.

**حمايات:** ما يستخدم `force push` أبد، يوقف إذا لاحظ ملف `.env` أو مفتاح سري، ولو
صار تعارض بين جهازين يوقف ويخلي شغلك محفوظ. وقتها قل له: «حل التعارض وارفع».

لإيقاف الحفظ التلقائي مؤقتًا: أنشئ `.claude/settings.local.json` وفيه
`{"disableAllHooks": true}` (هذا الملف ما ينرفع).

---

## 3) قواعد بسيطة

1. **`main` لازم يبني دايم.** قبل ما تقول «خلصت»: `npm run build` و`npm test`.
2. **مهمة وحدة في كل مرة** من `docs/ROADMAP.md`، وعلّم عليها لما تخلص.
3. **لا تعدّل `package-lock.json` يدويًا**؛ ثبّت الحزم بـ `npm install <حزمة>`.
4. **المستودع مفتوح المصدر:** لا مفاتيح ولا كلمات مرور ولا بيانات شخصية في الكود.

### ممنوعات

- `git push --force`.
- `git reset --hard` أو حذف ملفات ما تعرف مصدرها.
- رفع ملفات `.env` أو أي مفاتيح (مستثناة في `.gitignore`).
