# دليل العمل المشترك على نبض

المستودع: https://github.com/waseem-42/Nabd — مفتوح المصدر (AGPL-3.0).

**الطريقة باختصار:** كلنا نشتغل على `main` مباشرة. ما فيه فروع ولا Pull Requests.
GitHub مكان نحفظ فيه الكود ونتشاركه، بس.

---

## 1) أول مرة على جهاز جديد

```bash
gh auth login
gh repo clone waseem-42/Nabd
cd Nabd
npm install
npm run dev
```

إعداد هويتك في Git (مرة وحدة لكل جهاز):

```bash
git config --global user.name  "اسمك"
git config --global user.email "بريدك في GitHub"
```

---

## 2) المزامنة التلقائية

المشروع فيه hooks لـ Claude Code (`.claude/settings.json`) ولـ Codex (`.codex/hooks.json`):

| متى | وش يصير |
|---|---|
| **تفتح الجلسة** | يسحب آخر `main` ويعرض لك وش رفع زميلك |
| **كل ما يخلص من رد** | يحفظ تعديلاتك، يركّبها فوق آخر شي رفعه زميلك، ويرفعها على `main` |

ما تحتاج تسوي `commit` ولا `push` بنفسك.

**حمايات:** ما يستخدم `force push` أبد، يوقف إذا لاحظ ملف `.env` أو مفتاح سري، ولو
صار تعارض يوقف ويخلي شغلك محفوظ على جهازك. وقتها قل له: «حل التعارض وارفع».

لإيقاف الأتمتة مؤقتًا على جهازك: أنشئ `.claude/settings.local.json` وفيه
`{"disableAllHooks": true}` (هذا الملف ما ينرفع).

## 3) قواعد بسيطة عشان ما نخرّب على بعض

1. **`main` لازم يبني دايم.** قبل ما تقول «خلصت»: `npm run build` و`npm test`.
   إذا رفعت شي مكسور، زميلك يسحبه مباشرة.
2. **قسّموا الملفات.** المسارات في `docs/ROADMAP.md`: واحد على الحركة والمحتوى
   (`src/motion/`، `src/data/`، `scripts/`)، والثاني على الشاشات (`src/screens/`،
   `src/domain/`، `src/ui/`). ملفات الترجمة `src/i18n/*` مشتركة، فخلّوا تعديلاتها صغيرة.
3. **ارفع كثير.** الحفظ التلقائي يرفع بعد كل رد، فالتعارضات تطلع صغيرة وبدري.
4. **لا تعدّل `package-lock.json` يدويًا**؛ ثبّت الحزم بـ `npm install <حزمة>`.
5. **المستودع عام:** لا مفاتيح ولا كلمات مرور ولا بيانات شخصية في الكود.

### إذا ظهر تعارض

قل لـ Claude: «فيه تعارض، حله بدون ما تضيّع تعديلات أي طرف وارفع».

### ممنوعات

- `git push --force`.
- `git reset --hard` أو حذف ملفات ما تعرف مصدرها.
- رفع ملفات `.env` أو أي مفاتيح (مستثناة في `.gitignore`).

| تبي | قل |

| تشوف وش سوى زميلك | «وش الجديد على main؟» |
| تبدأ مهمة | «خذ المهمة الجاية من المرحلة الحالية في الخطة» |

| تتراجع عن تعديل | «تراجع عن آخر تعديل على ... بـ revert» |
